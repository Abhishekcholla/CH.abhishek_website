# Abhishek Cholla — Multi-page Portfolio

GitHub Pages-ready static portfolio with:
- Home
- About / complete portfolio
- Projects
- Gallery
- Connect
- Algo Trading / Markets dashboard
- Client-side visitor counter
- Responsive navigation

## Market data
The Markets page embeds TradingView financial widgets for gold, silver, crude oil, indices, stocks and market news. TradingView says widgets contain built-in data, but real-time availability varies by market/exchange and some exchange data may be delayed. See TradingView's widget data documentation before relying on it for trading decisions.

## GitHub Pages
Upload all files to a repository and enable Settings → Pages → Deploy from branch → main → root.

## Visitor counter
The visitor count uses a public counter endpoint from the browser. If you want a production-grade analytics/counter solution, replace it with your preferred provider.

## Personal social links
Update the GitHub/Instagram/Facebook/X URLs once the personal profile URLs are known.
